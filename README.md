XLSX to CSV Converter & Data Cleaner
A fast and automated tool that converts Excel (.xlsx) files to .csv format while cleaning the data. Built with Java and PowerShell, it automatically removes invisible spaces, fixes typos, and evaluates Excel formulas to export clean, ready-to-use data.






Excel CSV Dönüştürücü 
Excel (.xlsx) dosyalarını yüksek hızda .csv formatına dönüştüren ve bu sırada verileri otomatik temizleyen bir araçtır. Java ve PowerShell ile geliştirilmiştir. Dönüşüm esnasında görünmez boşlukları siler, yazım hatalarını düzeltir ve formülleri hesaplayarak temiz bir veri çıktısı verir.
